Zero-Trust Multi-Tenancy

Every single database query enforces tenant_id = auth.uid() via PostgreSQL Row-Level Security (RLS). Cross-tenant leakage is mathematically impossible.

Version-Pinned Workflows

Live workflow instances are pinned to the published schema version active at inception. Re-publishing a workflow never breaks in-flight approvals.

Safety Guardrail (Human-in-Loop)

Per BRD non-functional requirements, AI agents are strictly advisory for Life Safety (M20) and High-Value Financials (M21/M22). Human confirmation is enforced.

Hybrid File Architecture

High-volume site photos and CAD drawings bypass Fastify server memory limits (via presigned URLs direct to CDN) while maintaining strict permission-controlled download URLs.

Autonomous AI Agents, Model Context Protocol (MCP) & Retrieval-Augmented Generation (RAG)

How Sevents OS bridges Large Language Models with construction ERP tools, pgvector embeddings, and human audit approval.

1. Vector RAG Pipeline (M28)

Contract documents, specs, architectural drawing metadata, and safety regulations are automatically chunked and indexed.

1 Document Upload & Text Extraction (OCR)
2 512-Token Overlapping Semantic Chunking
3 OpenAI text-embedding-3-small Vectorization
4 pgvector Cosine Similarity Match with RLS
5 Context-Injected Grounded Answer with Citations
Guarantees zero hallucinations by grounding answers strictly in approved tenant records.
2. Agent Studio & ERP Tools (M29)

Agents are assigned specialized domain roles with strict boundaries and specific ERP tool permissions.

Estimating Copilot
Tools: query_catalogue_norms, calc_boq_margin
Site Operations Auditor
Tools: read_dpr_logs, flag_weather_delay
Safety & HSE Screener
Tools: classify_hazard_risk, draft_ptw_conditions
Commercial Claims Assessor
Tools: audit_subcontractor_claim, diff_po_grn
Built on Model Context Protocol (MCP) standards for clean modularity.
3. Human-in-the-Loop & Audit (M30)

Autonomous execution runs in sandbox queues with mandatory human approval gates before executing write operations.

Autonomous Advisory Mode:

Agent analyzes inputs, retrieves data, formulates recommendation & drafts the transaction record.

Interception Barrier:

If action modifies financial records or site safety status, agent creates an approval ticket in M07 / M08.

Authorized Sign-off:

Designated role (Project Manager, QS, QHSE Lead) reviews side-by-side diff and provides cryptographic approval.

Immutable Telemetry:

Execution steps, token usage, latency, and prompt hashes logged permanently in M35 audit logs.

Complies with Enterprise Governance, ISO 9001 and UAE Federal Safety regulations.

Technical Engineering, CAD/BIM & Quantity Surveying Workflow

Explains where technical team assets (architectural drawings, structural models, RFIs, BOQs, quantity take-offs) live and how they connect to field delivery.

Technical Team Roles
  • Chief Architect & Designers: Author design briefs, upload CAD/BIM files, manage revision stamps (REV-A, B, C).
  • Quantity Surveyor (QS): Performs quantity take-offs, links items to M05 Work Catalogue, computes margins.
  • Structural / MEP Engineers: Issue and resolve RFIs (Requests for Information), inspect site installations against drawings.
IFC Gate (M12 / M13)

No technical drawing is released to the site until it passes the Issued for Construction (IFC) Release Gate. Drawings in "Draft" or "Consultant Review" are locked against site PO issuance to prevent costly structural rework.

Work-Item Catalogue (M05)

Contains the company's 1,308-row canonical work-item catalogue with standardized labor and material cost norms. Estimators assemble tender bids by picking validated norms rather than guessing rates.
